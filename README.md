# 🌱 Agro Forte e Sustentável

Projeto web desenvolvido com HTML, CSS e JavaScript para promover práticas agrícolas sustentáveis e inovação no agronegócio.

## 🚜 Funcionalidades

* Página responsiva com tema agro sustentável.
* Seção sobre agricultura sustentável.
* Cards de projetos agrícolas.
* Links úteis para instituições do setor agro.
* Interatividade com JavaScript.

## 🌎 Links de Referência

* https://www.embrapa.br
* https://www.gov.br/agricultura
* https://www.fao.org/brazil

## 🛠 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## 📌 Objetivo

Divulgar informações e iniciativas que fortalecem o agronegócio de forma sustentável, unindo produtividade, tecnologia e preservação ambiental.
